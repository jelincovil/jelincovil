## Teaching

### Time Series Forecasting and MLOps

**[repositorio-forecasting-data-science](https://github.com/jlincovilc-pe/repositorio-forecasting-data-science)**

A professional, reproducible course on forecasting and MLOps: eight real datasets, eight notebooks run end to end, a 122-page monograph and an interactive presentation. The course's thesis is explicit and documented experiment by experiment: **complexity does not guarantee improvement**; in four of the eight experiments the naive baseline (seasonal naive, ETS) matches or is only barely beaten by the sophisticated model.

### Sistemas de Inteligencia Causal

**[sistemas_inteligencia_causal_estudiante](https://github.com/jlincovilc-pe/sistemas_inteligencia_causal_estudiante)**

ECO-490 / ECON-540 (2026). Sixteen weeks and 32 sessions split 50% theory / 50% production. Monorepo with a 32-chapter monograph, Series A notebooks (case studies) and Series B (production), 27 labs and a final project. The focus is effect estimation with machine learning together with system engineering; the Hugging Face layer is optional and everything runs locally.

### DES504 · Inferencia Causal Aplicada con Python

**[des504-inferencia-causal](https://github.com/jlincovilc-pe/des504-inferencia-causal)**

Master's programme in Statistical Science and Engineering, UNI. Unifying framework: the **Geometry of Statistical Causality (GCE)**, with the master chain |ATE| ≤ W₁ ≤ W^{G,1}. Thirty-two chapters, 32 notebooks, a PDF book and a Jupyter Book. Working principle **Proofs-to-Python**: every proven bound is checked with `assert`, seed 42, and mandatory validation of assumptions.
